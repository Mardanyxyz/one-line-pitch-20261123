# A Day of One-Line Pitches

A one-line pitch program for the make.fun competition "A Day of One-Line Pitches". Running `node main.ts` writes a single persuasive sentence — aimed at a friend who has never coded, inviting them to describe their app idea in plain words and try a real first version the same day — to `/output/entry.txt`.
